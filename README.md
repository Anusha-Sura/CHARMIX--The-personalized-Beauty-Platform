💄 Charmix – Personalized Beauty E-commerce Platform

Charmix is a full-stack beauty e-commerce application that delivers a personalized shopping experience for users based on preferences, behavior, and product categories. The platform integrates a user-friendly interface with a robust backend system to simulate a real-world online retail environment.

🚀 Features
👤 User Features

User registration & login authentication

Personalized product recommendations

Browse products by category (skincare, makeup, etc.)

Search and filter functionality

Add to cart & secure checkout

Order summary and tracking

🛠️ Admin Features

Admin dashboard for product management

Add, update, delete products

Manage inventory and pricing

View customer orders

⚙️ Installation & Setup
1. Clone the Repository
git clone https://github.com/Anusha-Sura/CHARMIX--The-personalized-Beauty-Platform/edit/main/README.md
2. Install Dependencies
pip install -r requirements.txt
3. Setup Database

Create a MySQL database

Import the SQL file from /database

Update DB credentials in the config file

4. Run the Application
python main.py
